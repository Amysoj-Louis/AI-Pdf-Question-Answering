# AI PDF Question Answering

A RAG-based PDF question-answering system leveraging local LLMs and vector embeddings for private, context-aware document interrogation.

## Features
- **Context-Aware QA**: Answers questions based strictly on the provided PDF content.
- **RAG Architecture**: Uses Retrieval-Augmented Generation for high accuracy.
- **Private & Local**: Designed to run locally to ensure data privacy.

## Tech Stack
- Python
- LangChain / LlamaIndex
- Local LLM Integration
